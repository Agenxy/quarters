# Quarters native binary

This package is an architecture-specific component of
[`quarters-cli`](https://www.npmjs.com/package/quarters-cli). Install the main
package instead of selecting this package directly.

It contains the native Rust executable built from
<https://github.com/Agenxy/quarters>. Quarters' baseline redirects user-owned
state; it is not a sandbox or security boundary. The macOS executables are
unsigned and unnotarized in this alpha.

Apache-2.0.
